# Upstream and local adaptation

Adapted from [Mobbin's official skills](https://github.com/mobbin/skills) at commit [`79124d92763f6e85107386227a96bbc40479710e`](https://github.com/mobbin/skills/tree/79124d92763f6e85107386227a96bbc40479710e), inspected 2026-11-04. This is an independent local adaptation, not an official Mobbin product.

The workflow follows `skills/redesign-screen/SKILL.md`, its preservation, taste, variations, report and before/after references, plus `skills/search/SKILL.md`. Source text and method were adapted into this skill and its local references. The unmodified upstream MIT notice is retained below.

| Upstream behaviour | Local adaptation |
| --- | --- |
| Scope the job, freeze Preserve, group references, plan moves, apply, check, show before/after | Retained as the core workflow with our local board and capture helpers |
| Search requires Mobbin's screens/flows/sections | Public demos, help galleries, walkthroughs, source assets, supplied images and local library; optional services are interchangeable |
| Cited evidence links to `mobbin_url` | Original product/help/repository URL plus inspected local asset and state/date |
| `search` invokes `best-practices`; report invokes `plain-writing` | Local search/report instructions contain the needed method; no hidden external skill invocation |
| Mandatory scoping rounds, selection gates and closing menus | Existing user authority and reversible choices proceed directly; ask only material questions |
| Five changes per pass and three correction rounds | Small verifiable groups without silently dropping in-scope work or declaring success by count |
| Mobbin-specific board/assets and canvas capabilities | Existing local board; available browser or design tools; explicitly labelled mockups where appropriate |
| Original reference-service coverage | Public-source coverage is recorded honestly; no claim to reproduce its paid corpus |

The finance/AI catalogues, optional-provider policy and capability-aware competitive judgement panel are local additions. Other researched skills are compared in `research/github-skills.md`; their code/resources were not imported.
