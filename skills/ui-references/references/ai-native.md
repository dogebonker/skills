# AI, developer tools and native product references

Research date: 2026-11-04. This is an on-demand catalogue for choosing reference **flows**, not a collection of mandatory templates or a ranking of entire brands. All sources below are public first-party pages, documentation or repositories. No Mobbin subscription or integration is required.

## Taste and evidence

The user's strongest stated preferences are **Herdr GPUI** and **T3 Code**: smooth, minimal and calm. Treat that preference as the starting point when choosing a direction. The user explicitly dislikes the Codex and Claude Code graphical interfaces; do not select them as visual targets by default.

The sources were opened and their text/asset links inspected. **No product was installed, logged into, interactively tested or visually benchmarked in this research.** Product screenshot links are available for several entries, but the image pixels were not inspected. A source's presence here therefore qualifies it for capture and comparison, not automatic design approval. “Study” and “mismatch” below are editorial hypotheses to check against the actual target task. Claims of speed or polish on vendor pages are not measured evidence.

Prefer a specific public help article, screenshot, demo or video over a homepage. Record the exact asset URL, screen/state, platform, date and what it proves. Product marketing screenshots establish appearance at most; they do not prove interaction quality. For motion, inspect the official demo video or a permitted local capture. If the needed authenticated state is unavailable, use a different reference or a user-provided capture rather than pretending it was inspected.

## First choices for this user's taste

| Need | Start with | What the eventual comparison should test |
| --- | --- | --- |
| Agent workspace and terminal shell | Herdr GPUI, T3 Code | Navigation stays quiet while task state, workspace identity and the next action remain visible. |
| Agent inbox and execution details | Craft Agents, Conductor | Distinguish active work, completed work, permission decisions and changed files without overwhelming the conversation. |
| Dense lists and filters | Linear, Raycast | Visible defaults, compact rows, discoverable contextual actions and keyboard access. |
| Calm writing or document surfaces | Bear, Craft, Things | Clear type hierarchy, restrained chrome, readable line length and details revealed when needed. |
| Native interaction foundations | Apple HIG; Samsung One UI for Android/mobile | Platform-appropriate navigation, focus, reachability, feedback and reduced-motion behaviour. |

These are selection priorities, not a finding that every named product achieves the same quality or suits every domain.

## How to use the catalogue without paid libraries

1. Name the task and state first: for example, “agent waiting for approval”, “portfolio with failed price refresh”, or “transaction list with filters applied”.
2. Pick two or three candidates whose actual flow matches. Consider the user's Herdr/T3 preference when the shell fits the target, and domain-specific financial references for money actions.
3. Find a public first-party screenshot, help article or video of that state. Search the official documentation before using staged marketing or third-party galleries.
4. Save permitted reference images locally with provenance. Mark a screenshot as staged, historical or unverified where applicable. Link to video evidence for motion rather than claiming a still proves smoothness.
5. Compare arrangement, hierarchy, density, controls and states side by side, then express the chosen structure through the existing design kit. A famous name alone never passes a reference-selection gate.
