# Reference catalogue

These are search candidates, not a universal ranking or a claim that every current screen is good. A famous brand earns a look; only an inspected screen earns a design decision. Nothing here requires a subscription or requires a particular product to be used.

| Task | Read | Start with |
| --- | --- | --- |
| Consumer banking, transfers, balances, cards | [Finance and crypto](finance.md) | Wise, Monzo, Revolut; select the actual state needed |
| Business banking, spend, invoices, approval queues | [Finance and crypto](finance.md) | Mercury's public demo, Ramp, Stripe |
| Wallets, send/swap, portfolio, onchain confirmations | [Finance and crypto](finance.md) | Phantom, Rainbow, Uniswap; use trading UIs only for trading tasks |
| AI workspaces, coding harnesses, diff review | [AI, native products and design systems](ai-native.md) | Herdr, T3 Code, Zed, Conductor; inspect the relevant current screen |
| Calm productivity, commands, keyboard navigation | [AI, native products and design systems](ai-native.md) | Linear, Raycast, Things, Craft |
| Platform behaviour, layout, accessibility and motion | [AI, native products and design systems](ai-native.md) | Apple HIG, Samsung One UI, Material; match the target platform |
| Marketing websites | The relevant product's public site | Treat this as marketing evidence, separately from its application UI |

Read only the relevant domain file and choose a few examples. The lists are deliberately broader than any single design run: do not feed every brand into a blended “premium” style. Prefer the user's chosen references and current constraints over this catalogue.

Use [search.md](search.md) to collect actual images, flows and timestamps. Record access and the checked version/date. A help page or gallery establishes where evidence can be found; it does not prove an unobserved interaction or the quality of an entire app. Recheck a source before relying on it, especially when a product or repository has moved.
